# MC Thanh Vân — Website

Website profile cá nhân của **MC Thanh Vân** — Professional MC & Event Host.

- **Live:** https://mcthanhvan.vercel.app
- **Phong cách:** dark glass premium, luxury

## Cấu trúc

- `index.html` — trang chính (hero, giới thiệu, dịch vụ, sự kiện, video, đặt lịch)
- `styles.css` — toàn bộ giao diện
- `script.js` — tương tác (menu, hiệu ứng, form đặt lịch)
- `assets/` — ảnh (chân dung + 6 sự kiện tiêu biểu, trích từ profile)

## Deploy

Site tĩnh, deploy trực tiếp lên Vercel (project `mcthanhvan`).
